# Product

## Register

product

## Users

OpenCode users checking AI-provider quotas while working in a terminal.

## Product Purpose

Show provider quotas, resets and session usage without interrupting development.
Complete original functionality before evolving the visual architecture.

## Brand Personality

Native, compact, informative. Inherit OpenCode's terminal theme and components.

## Anti-references

Do not introduce a separate web dashboard or decorative UI during migration.

## Design Principles

- Keep credentials and provider polling on the server.
- Distinguish unavailable data from exhausted quota.
- Preserve keyboard navigation and native OpenCode layout.
- Keep quick status compact; put detailed diagnostics in a scrollable view.

## Accessibility & Inclusion

Support keyboard-only operation, scrolling and small terminal viewports.
Use text labels alongside status colors and respect the host theme.
